# MARFA-webapp

Web interface for the MARFA molecular absorption calculator.

**Development of this project  is managed in GitLab; GitHub is a public mirror.**

Link to a web application: https://marfa.app/

Reference:
Razumovskiy, M., Fomin, B., & Astanin, D. (2025). [MARFA: An effective line-by-line tool for calculating molecular absorption in planetary atmospheres](https://doi.org/10.1016/j.jqsrt.2025.109599). *Journal of Quantitative Spectroscopy and Radiative Transfer, 346*, 109599.



For collaboration and code contributions, contact [razumovskii@phystech.edu](mailto:razumovskii@phystech.edu).
